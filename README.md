# Скачать видео — расширение для браузера

Простое расширение для Chrome, Edge, Яндекс.Браузера и Firefox. Оно находит видео на открытой странице и одной кнопкой сохраняет его на компьютер в обычном формате **MP4**. Такой файл открывается двойным щелчком в любом проигрывателе, в том числе в стандартном проигрывателе Windows.

Работает с обычными видеофайлами и с потоковым видео (HLS / `.m3u8`), которое многие сайты и онлайн-школы показывают вместо обычного файла.

## Установка

**Chrome / Edge / Яндекс.Браузер**
1. Скачайте `video-grabber-v1.4.zip` со страницы [Releases](../../releases/latest) и распакуйте его, например, в «Документы».
2. Откройте адрес `chrome://extensions` (в Edge — `edge://extensions`) и включите «Режим разработчика» (переключатель справа вверху).
3. Нажмите «Загрузить распакованное» и выберите распакованную папку `video-grabber`.

**Firefox** (версия 128 и новее)
1. Скачайте `video-grabber-v1.4-firefox.zip` (распаковывать не нужно).
2. Откройте адрес `about:debugging#/runtime/this-firefox` и нажмите «Загрузить временное дополнение…».
3. Выберите скачанный файл `video-grabber-v1.4-firefox.zip`.
4. Нажмите на значок пазла → шестерёнка у «Скачать видео» → «Всегда разрешать на всех сайтах».
5. Важно: Firefox убирает временное дополнение после перезапуска. Чтобы оно оставалось навсегда, загрузите этот же zip на [addons.mozilla.org](https://addons.mozilla.org/developers/) как «На своём сайте» (unlisted), получите подписанный `.xpi` и перетащите его в окно Firefox.

**Закрепите значок на панели**, чтобы он всегда был на виду: значок пазла → булавка напротив «Скачать видео». Появится **красный круглый значок с белой стрелкой вниз**.

## Как скачать видео

1. Откройте страницу с видео и нажмите ▶, чтобы видео начало играть.
2. На красном значке появится зелёная цифра: сколько видео найдено.
3. Нажмите на красный значок. Если видео одно, нажмите зелёную кнопку **«⬇ Скачать видео»**. Если их несколько, каждая кнопка подписана заголовком над видео (например, «1. Начинка», «2. Бисквит»); синяя кнопка **«⬇ Скачать все»** скачает их все.
4. Откроется вкладка скачивания. В ней спрашивается **«Куда сохранить видео?»**:
   - нажмите оранжевую кнопку **«📁 Выбрать папку»** и выберите папку, например флешку. Окно выбора открывается в папке, выбранной в прошлый раз;
   - видео при этом уже скачивается, а после выбора папки записывается прямо в неё, с процентами. В «Загрузках» лишней копии не остаётся;
   - можно также нажать «или сохранить в «Загрузки»».
5. Не закрывайте вкладку, пока не появится надпись **«Готово!»**. Кнопка **«▶ Посмотреть здесь»** позволяет сразу проверить, что видео сохранилось.

В Firefox выбор папки устроен иначе: когда видео скачается, откроется обычное окно «Сохранить как», и Firefox сам откроет в нём последнюю выбранную папку.

## Что оно не умеет

- Видео с защитой от копирования (DRM: Widevine, PlayReady и т. п.) расширение не скачивает и сообщает об этом.
- Пока папка не выбрана, скачанное хранится в памяти браузера. Для очень длинных роликов (несколько гигабайт) лучше выбрать папку сразу — тогда видео пишется прямо на диск.

## Правила использования

Расширение предназначено для личных копий видео, к которым у вас есть законный доступ, например чтобы смотреть оплаченные уроки без интернета. Не распространяйте скачанные материалы без разрешения правообладателя и соблюдайте правила сайтов, которыми пользуетесь.

## Как это устроено

- `background.js` отслеживает сетевые запросы вкладки и замечает видеофайлы и плейлисты HLS.
- `popup.html/js` показывает окно с кнопкой «Скачать видео».
- `download.html/js` скачивает части видео и по порядку записывает их прямо в выбранную папку (поддерживается стандартное шифрование HLS AES-128).
- `mp4.js` перепаковывает поток в MP4 без перекодирования, поэтому качество не теряется. Для этого используется библиотека [mux.js](https://github.com/videojs/mux.js) (Apache-2.0, текст лицензии в `mux.LICENSE.txt`).
