# Скачать видео — расширение для браузера

Простое расширение для Chrome, Edge, Яндекс.Браузера и Firefox. Оно находит видео на открытой странице и одной кнопкой сохраняет его на компьютер в обычном формате **MP4**. Такой файл открывается двойным щелчком в любом проигрывателе, в том числе в стандартном проигрывателе Windows.

Работает с обычными видеофайлами и с потоковым видео (HLS / `.m3u8`), которое многие сайты и онлайн-школы показывают вместо обычного файла.

## Установка

**Chrome / Edge / Яндекс.Браузер**
1. Скачайте `video-grabber-v1.8.1.zip` со страницы [Releases](../../releases/latest) и распакуйте его, например, в «Документы».
2. Откройте адрес `chrome://extensions` (в Edge — `edge://extensions`) и включите «Режим разработчика» (переключатель справа вверху).
3. Нажмите «Загрузить распакованное» и выберите распакованную папку `video-grabber`.

**Firefox** (версия 128 и новее)
1. Скачайте `video-grabber-v1.8.1-firefox.zip` (распаковывать не нужно).
2. Откройте адрес `about:debugging#/runtime/this-firefox` и нажмите «Загрузить временное дополнение…».
3. Выберите скачанный файл `video-grabber-v1.8.1-firefox.zip`.
4. Нажмите на значок пазла → шестерёнка у «Скачать видео» → «Всегда разрешать на всех сайтах».
5. Важно: Firefox убирает временное дополнение после перезапуска. Чтобы оно оставалось навсегда, загрузите этот же zip на [addons.mozilla.org](https://addons.mozilla.org/developers/) как «На своём сайте» (unlisted), получите подписанный `.xpi` и перетащите его в окно Firefox.

**Закрепите значок на панели**, чтобы он всегда был на виду: значок пазла → булавка напротив «Скачать видео». Появится **красный круглый значок с белой стрелкой вниз**.

## Как скачать видео

1. Откройте страницу с видео и нажмите ▶, чтобы видео начало играть.
2. На красном значке появится зелёная цифра: сколько видео найдено.
3. Нажмите на красный значок. Если видео одно, нажмите зелёную кнопку **«⬇ Скачать видео»**. Если их несколько, каждая кнопка подписана заголовком над видео (например, «1. Начинка», «2. Бисквит»); синяя кнопка **«⬇ Скачать все»** скачает их все.
4. Откроется вкладка скачивания. В ней спрашивается **«Куда сохранить видео?»**:
   - нажмите оранжевую кнопку **«📁 Выбрать папку»** и выберите папку, например флешку. Окно выбора открывается в папке, выбранной в прошлый раз;
   - видео при этом уже скачивается, а после выбора папки записывается прямо в неё, с процентами. В «Загрузках» лишней копии не остаётся;
   - можно также нажать «или сохранить в «Загрузки»».
5. Не закрывайте вкладку, пока не появится надпись **«Готово!»**. Кнопка **«▶ Посмотреть здесь»** позволяет сразу проверить, что видео сохранилось.

В Firefox выбор папки устроен иначе: когда видео скачается, откроется обычное окно «Сохранить как», и Firefox сам откроет в нём последнюю выбранную папку.

## Что оно не умеет

- Видео с защитой от копирования (DRM: Widevine, PlayReady и т. п.) расширение не скачивает и сообщает об этом.
- В обычном режиме, пока папка не выбрана, скачанное хранится в памяти браузера. Экономный режим использует временный файл на диске, в том числе при сохранении в «Загрузки».

## Правила использования

Расширение предназначено для личных копий видео, к которым у вас есть законный доступ, например чтобы смотреть оплаченные уроки без интернета. Не распространяйте скачанные материалы без разрешения правообладателя и соблюдайте правила сайтов, которыми пользуетесь.

## Как это устроено

- `background.js` отслеживает сетевые запросы вкладки и замечает видеофайлы и плейлисты HLS.
- `popup.html/js` показывает окно с кнопкой «Скачать видео».
- `download.html/js` скачивает части видео и по порядку записывает их прямо в выбранную папку (поддерживается стандартное шифрование HLS AES-128).
- `hls.js` выбирает качество вместе с соответствующим звуком, разбирает плейлисты и диапазоны байтов. Раздельные дорожки и их исходные MP4 скрываются из списка отдельных видео.
- `mp4.js` объединяет раздельные дорожки fMP4 в один MP4, сохраняя их временные метки. Поток MPEG-TS перепаковывается с помощью [mux.js](https://github.com/videojs/mux.js) (Apache-2.0, текст лицензии в `mux.LICENSE.txt`). Перекодирования нет, поэтому качество не теряется.

## Исправление звука в версии 1.5

Некоторые плееры, в том числе Kinescope, передают изображение и звук отдельными дорожками. В версии 1.4 скачивалась только видеодорожка, а исходные MP4 могли появляться отдельными кнопками. Версия 1.5 учитывает связь `AUDIO` в HLS, загружает нужные диапазоны `EXT-X-BYTERANGE` и объединяет обе дорожки в один файл. Ошибка загрузки звука прерывает сохранение.

Если расширение уже установлено из этой папки, откройте `chrome://extensions` (или `edge://extensions`), нажмите «Обновить» на карточке расширения, обновите страницу урока и снова запустите видео. Уже сохранённые файлы без звука нужно скачать заново.

## Обозначения дорожек в версии 1.6

В списке файлов и на странице скачивания показывается состав дорожек:

- **🎵 Только аудио** — фиолетовая кнопка, файл сохраняется как `.m4a`.
- **🎬 Видео без звука** — в проверенном заголовке есть только изображение.
- **🎬 Видео со звуком** — есть обе дорожки либо мастер-плейлист позволяет скачать их вместе.
- **❔ Состав дорожек пока не определён** — данных для проверки не хватило.

Расширение проверяет дорожки в заголовке MP4 и связи в HLS-плейлисте. Само расширение `.mp4` не означает наличие изображения: такой контейнер может содержать только звук. Отдельный аудиофайл больше не подписывается как скачанное видео.

У объединяемого ролика есть подпись **«🔗 Видео и звук — один файл»**. Связанные дорожки и качества группируются под его кнопкой. Подтверждённые дубли плейлистов скрываются с подписью **«♻ Скрыто подтверждённых дублей: …»**. Для этого сравнивается состав сегментов, их диапазоны, шифрование и длительность. Совпадения только по названию отмечаются как **«Совпадает название; дубль не подтверждён»** и остаются доступными.

## Проверка для разработчика

Нужны Node.js, FFmpeg и ffprobe в `PATH`. Запуск: `node --test tests/regression.test.cjs`.
Тесты проверяют разбор обезличенных плейлистов Kinescope, выбор аудиодорожки, диапазоны байтов, список найденных видео, ошибки загрузки и сохранение HLS в MP4. Для проверки результата создаются короткие тестовые видео с тоном, затем итоговый MP4 декодируется и проверяется наличие ненулевых аудиоданных. Личные видео для запуска тестов не нужны.

Сборка архивов Chrome и Firefox: `./build.ps1`. Архивы появляются в `dist/`; состав и контрольные суммы файлов проверяются при сборке.

## GetCourse и Kinescope в версии 1.7

- Дорожки Kinescope группируются по ID и хосту плеера. Различия в качестве, языке и параметрах ссылок больше не превращают один ролик в несколько независимых кнопок.
- Если мастер не попал в сетевой журнал, расширение пробует получить его по адресу этого же плеера. Если он недоступен, две захваченные дорожки одного ролика используются как пара видео + аудио.
- Под кнопкой скачивания можно раскрыть «Качество и язык звука». По умолчанию выбирается лучшее качество и стандартная аудиодорожка. Смена качества обновляет список совместимых языков.
- Поиск учитывает `data-master`, `data-video-src` и конфигурацию встроенных плееров. Дополнительные ссылки из HTML проверяются только для текущего сайта и известных хостов GetCourse/Kinescope, без передачи cookies и без рекурсивного обхода страниц.
- Перед завершением HLS-загрузки проверяются реальные кадры и аудиопакеты: длительность, разрывы временных меток и наличие данных. Проверка заголовка с заявленной длительностью не считается доказательством полноты. При недостающем звуке или неполной дорожке сохранение завершается ошибкой.
- В разделе «Другой способ скачивания» готовится команда PowerShell для внешнего yt-dlp или FFmpeg. Программы нужно установить отдельно; команда копируется и запускается пользователем, автоматически ничего не устанавливается и не запускается. Для защищённых входом потоков внешнему загрузчику может дополнительно потребоваться авторизация.

Новые возможности не добавляют поддержку DASH, смены инициализации HLS и DRM. Источники технических идей описаны в SOURCES.md.

## Экономный режим в версии 1.8

Предназначен для ноутбуков с небольшим объёмом RAM. Включён по умолчанию; переключатель вверху окна расширения запоминает выбор.

- Для HLS по умолчанию выбирается лучшее качество до 720p. Если доступны только более высокие разрешения — самое низкое из них. Выбранное вручную качество сохраняет приоритет. Обычный MP4 не перекодируется и остаётся в исходном разрешении.
- Одновременно загружаются две части вместо шести. Запись ограничивает чтение сети: новые данные не ставятся в бесконечную очередь, если диск медленный.
- Скачанное записывается во временный файл в приватном хранилище браузера (OPFS). В RAM остаются текущие части, а не полный фильм. Это действует для выбора папки и для «Загрузок».
- «Скачать все» использует одну вкладку и сохраняет уроки последовательно. Следующий урок начинается после сохранения предыдущего. Папка переиспользуется, пока браузер разрешает доступ; Firefox может спрашивать место для каждого файла.
- Отдельные загрузки в экономном режиме также ждут друг друга. Ошибка останавливает очередь; после исправления причины можно повторить текущий ролик.
- Временный файл удаляется после сохранения или ошибки. Оставшиеся после аварийного закрытия файлы удаляются при следующем запуске экономной загрузки.
- В экономном режиме один HLS-фрагмент ограничен 32 МБ. Если сайт отдаёт более крупные фрагменты, расширение предложит снизить качество или отключить режим.

Нужны современный браузер с OPFS и Web Locks и свободное место на системном диске. На этапе сохранения могут одновременно существовать временная и конечная копии. Если дисковое хранилище недоступно, скачивание не начинается; скрытого перехода к накоплению фильма в RAM нет. Для очень длинных роликов заранее проверьте свободное место.
