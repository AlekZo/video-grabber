# Скачать видео — расширение для браузера

Простое расширение для Chrome, Edge, Яндекс.Браузера и Firefox. Оно находит видео на открытой странице и одной кнопкой сохраняет его на компьютер в обычном формате **MP4**. Такой файл открывается двойным щелчком в любом проигрывателе, в том числе в стандартном проигрывателе Windows.

Работает с обычными видеофайлами и с потоковым видео (HLS / `.m3u8`), которое многие сайты и онлайн-школы показывают вместо обычного файла.

## Установка

1. Скачайте архив `video-grabber-vX.Y.zip` со страницы [Releases](../../releases/latest) и распакуйте его в любую папку, например в «Документы».
2. **Chrome / Edge / Яндекс.Браузер:**
   - откройте адрес `chrome://extensions` (в Edge — `edge://extensions`);
   - включите «Режим разработчика» (переключатель справа вверху);
   - нажмите «Загрузить распакованное» и выберите распакованную папку.
3. **Firefox** (версия 128 и новее):
   - откройте адрес `about:debugging#/runtime/this-firefox`;
   - нажмите «Загрузить временное дополнение…» и выберите файл `manifest.json` из распакованной папки;
   - важно: Firefox убирает такое дополнение после перезапуска браузера.
4. **Закрепите значок на панели**, чтобы он всегда был на виду. Нажмите на кнопку расширений (значок пазла) рядом с адресной строкой, затем на булавку напротив «Скачать видео». Появится **красный круглый значок с белой стрелкой вниз**.

## Как скачать видео

1. Откройте страницу с видео и нажмите ▶, чтобы видео начало играть.
2. На красном значке появится зелёная цифра: видео найдено.
3. Нажмите на красный значок, затем на большую зелёную кнопку **«⬇ Скачать видео»**.
4. Откроется вкладка с процентами. Не закрывайте её, пока не появится надпись **«Готово!»**.
5. Нажмите **«▶ Открыть видео»** или **«📁 Показать в папке»**. Файл лежит в папке «Загрузки».

## Что оно не умеет

- Видео с защитой от копирования (DRM: Widevine, PlayReady и т. п.) расширение не скачивает и сообщает об этом.
- Во время скачивания видео целиком хранится в памяти браузера. Для очень длинных роликов (несколько гигабайт) нужно столько же свободной оперативной памяти.

## Правила использования

Расширение предназначено для личных копий видео, к которым у вас есть законный доступ, например чтобы смотреть оплаченные уроки без интернета. Не распространяйте скачанные материалы без разрешения правообладателя и соблюдайте правила сайтов, которыми пользуетесь.

## Как это устроено

- `background.js` отслеживает сетевые запросы вкладки и замечает видеофайлы и плейлисты HLS.
- `popup.html/js` показывает окно с кнопкой «Скачать видео».
- `download.html/js` скачивает части видео и склеивает их по порядку (поддерживается стандартное шифрование HLS AES-128).
- `mp4.js` перепаковывает поток в MP4 без перекодирования, поэтому качество не теряется. Для этого используется библиотека [mux.js](https://github.com/videojs/mux.js) (Apache-2.0, текст лицензии в `mux.LICENSE.txt`).
